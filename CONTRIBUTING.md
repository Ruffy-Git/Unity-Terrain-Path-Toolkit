# Contributing

Thanks for considering a contribution.

This project is in early development, so discussion before large changes is encouraged.

## Ways to contribute

- Reproduce and report bugs.
- Suggest authoring workflows.
- Improve documentation.
- Add focused tests.
- Submit small, reviewable pull requests.

## Bug reports

Please include:
- Unity version
- Render pipeline if relevant
- Reproduction steps
- Expected behavior
- Actual behavior
- Console errors/warnings
- Screenshots or a minimal reproduction when useful

## Pull requests

Keep changes focused. Explain the problem being solved, how the change works, and how it was tested. Avoid committing generated Unity folders such as Library, Temp, Logs, or Obj.
